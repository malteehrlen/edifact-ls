# How to use the backlog
Milestones are created by humans. All other backlog items are created by agents. A milestone consists of one or more epics with clearly defined acceptance criteria. An epic consists of one or more user stories with clearly defined acceptance criteria. User stories as well as epics have dependencies that help agents parallelize work. Each story should consist of the feature itself plus tests and other validations needed. After an epic is implemented, it is time to reflect (like a retro) if things are progressing well or adjustments should be made before continuing. Always ask for permission before starting implementing a new epic.
